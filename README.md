# 📝 Sign-Up Project (Java Console Application)

A simple, user-friendly command-line user registration and authentication simulation built in **Java**. Handle account creation, username/password validation, and login flows right from your terminal.

---

## 🚀 Features

* **User Registration:** Create a new account by providing a username and a secure password.
* **Credential Validation:** Basic input validation to check for empty fields or invalid formats.
* **Login Authentication:** Verify user credentials against stored data to grant access.
* **Interactive Console Menu:** Simple, loop-based menu for seamless navigation between sign-up, login, and exit options.

---

## 🛠️ Technologies Used

* **Language:** Java (JDK 17 or higher)
* **Interface:** Command-Line Interface (CLI) / Standard Console I/O (`Scanner`)
